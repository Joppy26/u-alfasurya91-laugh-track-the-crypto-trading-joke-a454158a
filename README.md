One line, under 200 characters, about crypto and trading life. This program writes a single fixed joke to `/output/entry.txt`.

## The joke

> Bought the dip. The dip had a basement. The basement had my life savings.

## Run

```sh
node main.ts
```

No network, no randomness, no input. The same joke is written every run.
